# Basic Keylogger using Java

## Project Description
This project is a simple Keylogger developed using Java. The program captures keyboard inputs and logs the pressed keys into a text file. It demonstrates how keyboard events can be handled in Java and how the recorded data can be stored using file handling.

## Features
- Captures keyboard inputs
- Records pressed keys
- Saves keystrokes into a text file
- Uses Java Swing for GUI
- Implements Java KeyListener for detecting key events

## Technologies Used
- Java
- Java Swing
- File Handling (FileWriter)

## How It Works
1. The program opens a basic window.
2. When a key is pressed, the program captures the key event.
3. The pressed key is recorded in a text file named `keystrokes.txt`.

## Output Example

Key Pressed: E  
Key Pressed: L  
Key Pressed: L  
Key Pressed: O
